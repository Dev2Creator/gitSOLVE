## 🍃 Why gitSOLVE?

The GitHub star economy is completely cooked. 

The trending feed is 90% AI wrapper hype, tutorial clones, and the same 50 corporate mega-projects trading stars. Meanwhile, solo engineers spend months building **flawless, zero-dependency, SIMD-accelerated, battle-tested tools** in the dark... and end up with **3 stars** (one from their alt account, one from a friend, and one from a bot). 💀

### 1. 📡 The Radar (`/radar`)
Set your search parameters (language, topic, ecosystem) and let the engine filter the signal from the noise:
* **Star Gate**: Configurable range (default `2..7` stars).
* **Pulse Check**: Active commit in the last 30 days (still maintained).
* **Maturity Check**: Created at least 60 days ago (no weekend throwaways).
* **Originality Guard**: Zero forks, zero mirrored scrapers.

### 2. 🔬 Deep X-Ray Code Inspection (`/xray <repo>`)
Before displaying a candidate, `gitSOLVE` puts it under the microscope:
* **Real Code vs. Boilerplate**: Measures genuine handwritten logic vs. vendor code and templates.
* **Commit Forensics**: Inspects the git log for craftsmanship (`feat: eliminate lock contention` vs `test1`).
* **Test Suite Verification**: Confirms passing CI (`.github/workflows`) and tests (`tests/`, `benches/`).
* **Proof of Life**: Scans documentation for real architecture diagrams, benchmark tables, and demo assets.

### 3. 🏆 The "I Was Here First" Vault (`/vault`)
Whenever you find a gem, tap `[s]` to tuck it into your local vault (`~/.config/gitsolve/vault.db`).
* Re-scans your saved gems on demand.
* Displays their current star counts vs. what they had when you found them.
* Gives you verifiable proof that you were an early believer before the hype train arrived.

## 🚀 Quickstart

### Installation

```bash
# Using uv (fastest)
uv tool install gitsolve

# Using pip
pip install gitsolve
```

### Jump Straight In

Just type **`gs`** to open the interactive command palette, exactly like `irl-pkg` and `irl-wisdom`:

```bash
# Launch the full-screen interactive dashboard
gs

# Or fire direct commands in one keystroke:
gs radar --lang rust --topic cli
gs fresh --lang python
gs xray owner/unhyped-repo
gs compare owner/repo-a owner/repo-b
gs author solo-creator
gs vault
gs lucky
gs theme cyber_peach
```

## 🧪 The Sleeper Index Formula

How does `gitSOLVE` calculate the **Sleeper Index**?

$$\text{Sleeper Score} = \min\left(100, \; \frac{\text{Substance Score}}{\text{Stars} + 1} \times 12\right)$$

Where **Substance Score (0 - 100)** is computed from:
* **Documentation Quality (20 pts)**: Setup guides, API docs, usage examples, diagrams.
* **Test Suite & CI (25 pts)**: Passing workflows, unit tests, integration tests, benchmark harnesses.
* **Commit Cadence & Forensics (20 pts)**: Semantic commit history spanning across multiple months.
* **Code Purity (20 pts)**: High ratio of core language logic vs generated glue code or vendor assets.
* **Modern Stack Hygiene (15 pts)**: Modern build systems (`pyproject.toml`, `Cargo.toml`, `go.mod`, etc.).

```
Score: 90 - 100  ──►  💎 MYTHIC SLEEPER   (Immediate must-read)
Score: 75 - 89   ──►  🔥 SOLID GOLD       (Production grade craftsmanship)
Score: 60 - 74   ──►  ✨ HIDDEN GEM       (Promising underground project)
```

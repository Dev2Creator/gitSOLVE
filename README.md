## 🔬 Explainable Scoring Framework

`gitSOLVE` rejects "black-box" magic numbers. Every repository is evaluated across two independent, explainable dimensions:

### 1. Repository Health Score (0 - 100)
Measures architectural discipline and code hygiene:
* **Automated Testing Suite (25 pts)**: Verified presence of test files (`tests/`, `*_test.go`, `test_*.py`, `benches/`).
* **CI/CD Automation (20 pts)**: Verified passing GitHub Actions workflow runs.
* **Documentation & Blueprint (20 pts)**: High-signal README with architecture diagrams, API specs, and copy-paste examples.
* **Code Purity & Density (20 pts)**: Language byte ratio prioritizing handwritten logic over auto-generated template bloat.
* **License & Build Hygiene (15 pts)**: Declared open-source license and modern packaging manifests (`Cargo.toml`, `pyproject.toml`, `go.mod`).

### 2. Discovery Potential Score (0 - 100)
Measures underground alpha and hidden value:
* **The Sweet Spot Gate (40 pts)**: Repositories in the `2..7` star range receive maximum discovery points; vanity projects with >500 stars are penalized.
* **Maturity Without Noise (30 pts)**: Repositories established >60 days ago that remain focused and handcrafted.
* **Originality (30 pts)**: Non-forked, distinct source trees with clean commit ancestry.

```
Overall Score: 88 - 100  ──►  💎 MYTHIC SLEEPER   (Elite alpha, immediate reading)
Overall Score: 74 - 87   ──►  🔥 SOLID GOLD       (Production-grade craftsmanship)
Overall Score: 60 - 73   ──►  ✨ HIDDEN GEM       (Promising underground tool)
```

## 🤖 Deep AI Forensics (Powered by Pollinations AI)

`gitSOLVE` integrates directly with **Pollinations AI** (`pollinations.ai`) to generate high-signal architectural dissections without needing expensive API keys.

```bash
# Generate a deep forensic verdict on any repo
gs ai hyper-simd/ring-buffer

# Or ask specific engineering questions
gs ask hyper-simd/ring-buffer -q "How does it handle memory barriers during wrap-around?"
```

Every AI teardown produces a strict 4-part breakdown:
1. **`VERDICT`**: What the codebase actually does under the hood and its core algorithmic model.
2. **`WHY THIS IS GOLD`**: Specific design choices, zero-allocation patterns, and craftsmanship.
3. **`UNDERGROUND EDGE`**: Why a senior developer would pick this over mainstream corporate libraries.
4. **`CAVEATS & RISKS`**: Maintainer bus factor, single-platform constraints, or missing edge cases.

> ⚡ **Offline Resilience**: When operating offline or without network connectivity, `gitSOLVE`'s deterministic forensic engine instantly generates high-signal architectural verdicts from verified AST and commit telemetry in under **0.001 seconds**.

### 🧩 Unix Pipeline & Scripting (`--json`)

Every subcommand supports `--json` for effortless integration with `jq`, `fzf`, and shell scripts:

```bash
# Pipe radar results directly to fzf and clone the selection
gs radar --lang rust --stars 1..5 --json | \
  jq -r '.[].html_url' | \
  fzf --preview 'curl -s https://api.github.com/repos/$(echo {} | cut -d/ -f4,5) | jq .' | \
  xargs git clone

# Extract top mythic sleepers with health score >= 90
gs fresh --json | jq '.[] | select(.health_score >= 90) | {name: .full_name, score: .overall_score}'
```

## 🛡️ Security, Privacy & Safety Guarantees

* 🔒 **Strictly Read-Only**: `gitSOLVE` never stars, forks, follows, or modifies your GitHub account. All token requests are strictly scoped to public metadata.
* 🛡️ **Terminal Injection Armor**: Every repo title, author, commit message, and description passes through Unicode NFKC normalizers and ANSI escape strippers. Malicious terminal control sequences cannot compromise your shell.
* 🚫 **Zero Telemetry**: No tracking cookies, no Google Analytics, no corporate telemetry pings.
* 🔑 **Token Safety**: GitHub tokens are stored locally in `~/.config/gitsolve/config.json` with strict user-only read permissions (`chmod 600`).
